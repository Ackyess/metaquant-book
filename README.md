# 诚实的量化交易

《诚实的量化交易：写给新手的第一堂课》1.1 的开放书籍仓库。

- `book.md`：中文完整源稿
- `book.en.md`：英文完整源稿
- `versions/`：中英文书稿的历史与精炼版本
- `assets/`：中英文封面
- `output/epub/`：EPUB 3 成品
- `output/pdf/`：A5 PDF 成品

本仓库只公开书籍内容，不包含网页阅读器、构建脚本或审计代码。
